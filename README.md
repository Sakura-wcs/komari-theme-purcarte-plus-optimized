# Komari Theme PurCarte Plus · 优化版

基于 [YoungYannick/komari-theme-purcarte-plus](https://github.com/YoungYannick/komari-theme-purcarte-plus) 的 [v2026.08.20.1](https://github.com/YoungYannick/komari-theme-purcarte-plus/tree/v2026.08.20.1) 构建的非官方优化版本。

在 Komari 后台的「导入远程主题」中粘贴以下 ZIP 下载链接（不要选 GitHub 自动生成的 Source code ZIP）：

https://github.com/Sakura-wcs/komari-theme-purcarte-plus-optimized/releases/download/v2026.08.20.1-optimized/komari-theme-purcarte-plus-optimized.zip

首页延迟加载图表和 3D 地球，压缩了背景视频并减小了页头 Logo。访客保护设置及原图未变。
